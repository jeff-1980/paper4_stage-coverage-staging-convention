# Data and code for "Stage-conditional coverage of RUL prediction intervals depends on the staging convention: evidence from C-MAPSS"

This repository contains the per-sample predictions, staging labels under both
conventions, and the scripts used to generate every table and figure in the note.

**Scope note:** this repository does not include a `forensics_2026-09-12_gate/`
directory or any investigation logs (`FINDINGS_LOG*.md`). That earlier stage of
work verified (and ultimately falsified) the headline claims of a separate,
unsubmitted manuscript that used the same C-MAPSS base model and Mondrian CP
implementation; it is not an input to this note and is intentionally excluded.
For the same reason, one superseded/buggy intermediate result
(`item2_six_method_multiseed.BUGGY_no_warmup.csv`) and one six-method
comparison table not used by the note's current pipeline
(`item2_six_method_multiseed.csv`) are also excluded from `forensics_2026-09-11/`.

## Directory overview

- `results/forensics_2026-09-11/` — initial multi-seed base-model training and
  standard (marginal) conformal prediction reproduction. Contains the trained
  Bayesian LSTM checkpoints and cached per-timestep predictions (`models/`)
  that later scripts reuse without retraining, plus the official-test-set
  standard-CP results used in Appendix A.
- `results/forensics_2026-09-14_relabel/` — the final same-sample relabeled
  results used directly in the note's Results section: per-sample predictions
  and interval widths under both staging conventions on identical held-out
  data, the three main tables, the mechanism-diagnostic CSVs/figures (Section
  4), and two small follow-up CSVs (see "Known gaps" below).
- `scripts/` — the scripts that generated the above (see mapping below). Data
  itself is not included: all base data is the public NASA C-MAPSS turbofan
  degradation dataset; scripts expect it at `~/论文4/data/cmapss/` (adjust the
  `DATA_DIR` constant in `train_multiseed.py` to your own path).

## Known gaps

Two of the CSVs in `results/forensics_2026-09-14_relabel/` were generated by
short `python3 -c "..."` one-liners during analysis, run directly against the
already-computed `per_sample_relabeled.csv`, and were not saved as standalone
script files at the time:

- `h_sensitivity_9row.csv`
- `worst_stage_consistency.csv`

Both are straightforward aggregations of columns already present in
`per_sample_relabeled.csv` (grouping by method/stage/(fd,seed) and computing
paired differences, means, and agreement counts respectively); a proper
standalone script for each is TODO. The CSVs themselves are included and are
exactly what the paper's §3.2 and §3.3 numbers are drawn from.

## Reproduction

Dependencies: Python 3, `numpy`, `pandas`, `torch`, `scipy`, `matplotlib`,
`scikit-learn`. GPU is not required (inference-only after training).

1. Download the NASA C-MAPSS dataset and point `DATA_DIR` in
   `train_multiseed.py` at it.
2. `python3 scripts/forensics_2026-09-11/train_multiseed.py` — trains the base
   model for all 4 subsets × 5 seeds (or skip this and use the checkpoints
   already in `results/forensics_2026-09-11/models/`).
3. `python3 scripts/forensics_2026-09-11/item1_standard_cp_reproduce.py` —
   regenerates the Appendix A source CSV.
4. `python3 scripts/forensics_2026-09-14_relabel/relabel_same_sample.py` —
   regenerates `per_sample_relabeled.csv` (the main data source; this is the
   slow step, one full pass of per-timestep inference per held-out unit).
5. `python3 scripts/forensics_2026-09-14_relabel/analyze_relabeled.py` —
   regenerates the three main `.tex` tables and the appendix table.
6. `python3 scripts/forensics_2026-09-14_relabel/clocks_and_residuals.py` then
   `python3 scripts/forensics_2026-09-14_relabel/redraw_residual_deciles.py` —
   regenerates the two figures.

All scripts write into `results/<forensics_dir>/` relative to the repository
root; adjust the `REPO`/`SOURCE_REPO` path constants at the top of each script
if you relocate the repository.
